# Capability preconditions and follow-ups, discoverable only by attempting

## Goal

Measured three times in real runs. A mode that cannot pre-flight stops every tool until the engagement is fixed. agent_task_convergence refuses unless a native formal task exists, and the refusal is the first place that is stated. agent_project_task creates a task whose acceptance.md is a placeholder, which the agent had to discover by reading the file. windows.host_info already declares preconditions in the registry, so the field exists and the native project capabilities do not use it; the fix is to declare them where the agent reads before it attempts.
