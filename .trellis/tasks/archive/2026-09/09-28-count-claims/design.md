**Every replacement is shorter or the same length**, which is the property that makes this a removal rather than a rewrite: a
count protected by adding words spends the room the next contract needs.

## The convention, and its honest limit

```text
A count of something the code declares is a claim with no reader.
The code will change; the sentence will not; and nothing connects them.
Name the declaration, or name the members.
```

**It is a convention and not a control**, and the guideline says so: prose cannot be checked, and a convention that read as a
control would be the defect this project keeps finding. What *can* be checked is checked - the labels by the typecheck, the
surface by its loader, the citations by the prohibition - and this is the residue.

## Verification

- **By measurement**: the loop specification is not larger afterwards, and the gate stays green.
- **By reading each replacement in place**, because a count removed from the wrong clause leaves a sentence that no longer
  says what it meant.
