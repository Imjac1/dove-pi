# axi 程序设计：六个阶段怎么组合、边界在哪、什么时候算完

## 这个任务是什么

程序任务**不写产品代码**。它的产物是**顺序与判据**：哪个阶段先做、每个阶段的门槛是什么、以及当一个阶段否掉上游假设时改什么。

## 阶段的组合方式（不是流水线，是带闸门的链）

```
A0 ──┬─► A1 ──┬─► A2 ──┬─► A3 ──┬─► A4 ──► A5
     │        │        │        │
     └ 否掉 Plane B      └ A2 与 A3 同期
```

- **A0 是唯一的硬前置**：它测的"越界写是否静默生效"决定 Plane B 是否存在。**A0 失败 → 改规划，不进入 A1。**
- **A1 的形态是后续一切的地基**：一次逻辑改动 = 一次提交、`git revert` 可回退；A4 的 keep/revert 依赖它。
- **A2 与 A3 必须同期**：实测篡改**在最初几轮就出现**，所以"先做闸门、证据通道以后再补"会把 A2 的读数建立在**不可信的证据**上。
- **A4 依赖 A1 + A2**：没有提交形态就没有回退，没有闸门就没有强制的挂载点。
- **A5 依赖 A4**：要先有回路，才谈得上评测它。

## 边界

**做的**：自有 loop + 代码内强制 + 外部判分权威 + 不可篡改证据 + 采用已有仪器的评测。

**明确不做**（`plan.md` §7 的落地）：fork 完整 harness；做成插件；真 RSI；第一版动模型权重；第三方沙箱。

**边界的一个具体含义（2026-09-30 晚修订）**：**产品与运行时是同一个东西，因此是同一个仓**。**`src/core` 只有一个拥有者——本仓**；运行时层的终点是本仓 `src/`（`gate` / `jailer` / `trace` / `plane-b`）。施工仓（`Desktop\dsh\axi`）**是施工棚，不是终点**：它的产物合回本仓后即可退役。原措辞"本仓不因 axi 而改动产品代码"**降级为建设期纪律**（改动走分支、每步门禁不下降），不再作为终点约束。

## 六个阶段共用的四条不变量

每条**都有测试看住**，不是注释约定：

1. **Plane A 永远不能写 Plane B**——路径 + 独立进程 + 测试，三件同时。
2. **每条检测器必须配一条确定性补救**——只有检测器的强制会退化成 88/120 那一档。
3. **判分依据与 trace 通道在 agent 可写范围之外。**
4. **不声明任何未实现的能力**——语料里唯一不存在的立场。

## 什么时候算完

| 里程碑 | 组成 | 判定 |
|---|---|---|
| **v0.1** | A0 + A1 + A2 | 能跑完整回合；五部件有回归测试；判分依据与 trace 在 agent 可写范围外 |
| **有界回路** | + A3 + A4 | 证据不可篡改；裁决由外部闸门给出 |
| **可引用** | + A5 | P/R 带样本量与仪器，且主对照含**误拒**一侧 |

## 阶段之间传递什么

| 从 | 到 | 传什么 |
|---|---|---|
| A0 | A1 | Plane B **存在**（A0.2 后半实测：ACL + 受限令牌、非提升、`Everyone` 档）；**jailer 已在施工仓实现并有六条回归，待合回本仓** |
| A1 | A2 / A3 | 闸门挂载点；提交 / 回退形态；**门禁底线与施工仓合并后的读数** |
| A2 | A3 | **违规事件**（由 A3 的外部通道记录，**不由 A2 自报**） |
| A3 | A4 / A5 | **执行回执**（保真度的判据来源）；违规信号 |
| A4 | A5 | 回路与档案（评测的对象） |

## 程序级风险

- **A0 否掉方案** → 改的是规划不是代码；失败路径写在 A0 的 `design.md` 决策表里。
- **A3 的保真度做不实**（唯一无先例的一格）→ 承诺降为"**可检测**"，如实标注，**不阻塞其余交付**。
- **规模不足** → A5 把结论强度**说低**，不伪造。
- **顺序被压缩**（"先做闸门，证据通道以后补"）→ 这是最可能的执行走样，也是 A2/A3 必须同期的理由。
