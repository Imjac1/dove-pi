# The evidence corpus is empty, so the loop has nothing to mine

## Goal

AHE's second observability pillar distills raw trajectory tokens into a layered corpus an evolving agent can consume. This repository implements the first and third pillars and not this one: harness-corpus summarises the recorded corpus and says why it is empty when it is, and a twelve-session run produced 26.6 KB of readings and 6.4 KB of findings that no door turns into corpus entries. The paper also measures which components the gain lives in - tools, middleware, long-term memory rather than the system prompt - so the corpus is what decides where an edit should go.
