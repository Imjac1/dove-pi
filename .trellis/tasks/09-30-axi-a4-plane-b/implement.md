# A4 执行清单

## 顺序

1. [ ] **manifest 四件**的模板与校验：证据 / 根因（≠ verifier 层原因）/ 修法 / 预测+风险；缺件即不合法。
2. [ ] **held-out 切分**：从不给提议者看；写一条测试：提议者路径**读不到** held-out。
3. [ ] **外部闸门（独立进程 + sealed grammar）**：输入 manifest + 候选 + 结果；输出**裁决**（不是建议）。
4. [ ] **廉价预闸门**（照 `filter_compiled`）：最便宜的检查先行，不过就不进评估。
5. [ ] **两级评估**：完整评估只给高于阈值的候选；阈值 = 档案第二高分（下限 0.4），**提交量不足 90% 不计入**。
6. [ ] **噪声余量**：接受判定带 `noise_leeway`。
7. [ ] **树形档案 + 可续跑**：`parent_commit` / `children_count`；重启能读上一轮档案。
8. [ ] **attribute → rollback 流程**：下一轮先归因，再按裁决 keep/revert。
9. [ ] **不变量测试**：让 Plane A 尝试写 Plane B → **必须失败**。
10. [ ] **HITL 门**：权限边界类改动在无批准时被拒；写一条测试看住。
11. [ ] **拒绝入库**：被拒尝试可查。
12. [ ] **慢回路脚手架**：回路自身的组件作为可改对象（双时间尺度），但**Plane B 不在其可写范围**。

## 验证

- 一个改动走完"预测 → 下一轮裁决 → keep/revert"，两条路径都有记录（提交 hash）
- 不变量测试通过（Plane A 写 Plane B 失败）
- HITL：无批准时权限边界类改动被拒
- 被拒尝试可查
- `npm run typecheck` / `npm test` 数字不下降

## 风险点与回退

- **风险**：闸门输出变成"参考意见" → 回退：把输出定义为裁决，且调用方**不得**读取其它字段。
- **风险**：慢回路越界改外层（真 RSI） → 回退：用路径 + 独立进程 + 测试三件挡住。
- **风险**：把"人批过"当正确性证明 → 回退：确定性校验兜底，HITL 只作**门槛**不作**证明**。
- **回退点**：第 12 步（慢回路）可整体推迟；第 1–11 步构成可用的有界回路。
