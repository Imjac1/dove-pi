# A4：Plane B 与改进回路

## Goal

让 axi 能真正走完一次**有界**自我改进：外部闸门裁决、held-out 切分、manifest 记录预测与风险、下一轮据裁决 keep 或 revert。

来源：`plan.md` §2.1、§4.2 A4。

## Background

- **四处一手来源同一条规则**：候选生成与发布权威分离（`2609.30219`）；受治的 harness 变更（解剖 §3.5.3）；模型与评测器固定（Self-Harness）；*"Freeze the evaluator and separate held-out tasks from search"*（RSI-Bench）。
- 现成机制：**双时间尺度**（MetaSkill-Evolve：快回路改技能、慢回路改回路的组件）；**SkillOpt**（冻结 agent + 外部工件 + 独立优化者 + 只在 held-out 增益下接受）；**DGM** 的机制（预闸门 / 两级评估 / 树形档案 / 噪声余量）。
- **一处必须抄准的差别**：DGM 的"接受"**不是**晋升门——它默认 `keep_all`，晋升靠"谁被选为父节点"隐式发生。axi **取它的机制，不取它的接受语义**。
- 保守晋升（Self-Harness）：只在两侧都不受损时接受。
- **拒绝也要入库**（AI4AI at Scale）；被接受的更新发布为**带版本的制品**（Reef）。
- **保留率实测约 3%**（Karpathy ~700 次实验保留约 20 个）→ 成本在**门**，不在提案。
- **人批不是万无一失**：`2609.30219` 实测 431 组人答配对里 **169 组放行了错误答案**。

## Requirements

- **R1** 外部闸门：候选只有在 sealed grammar 下能由**外部**推导时才被放行。
- **R2** held-out 切分**从不给提议者看**；判分依据在 agent 可写范围之外。
- **R3** manifest 四件：**证据**、**根因**（不等于 verifier 层的原因）、**修法**、**预测 + 风险**。
- **R4** 下一轮**先 attribute，再按裁决 rollback**；一次逻辑改动 = 一次提交。
- **R5** 权限边界类改动**必须 HITL**；且**不得把"人批过"当作正确性证明**——仍需确定性校验兜底。
- **R6** **拒绝的尝试也入库**（可审计经验）。
- **R7** 被采纳的更新是**带版本的制品 + 可回退提交**。
- **R8** 内层判分器可上升，外层评测器不可改；不变量：**Plane A 永远不能写 Plane B**。

## Acceptance Criteria

- **AC-1** 一个改动走完"**预测 → 下一轮裁决 → keep/revert**"，两条路径都有记录（提交 hash）。
- **AC-2** 权限边界类改动在**无 HITL 时被拒**，且这条由测试看住。
- **AC-3** 判分依据在 agent **可写范围之外**（有测试看住）。
- **AC-4** 被**拒绝**的尝试在库里可查。
- **AC-5** 门禁不下降。

## Out of Scope

- 自建评分（→ A5）；第一版**不动模型权重**。

## Key Decisions / 依赖

- 依赖 **A1**（提交 / 回退形态）与 **A2**（强制挂载点）。
- 接受语义用 **Self-Harness 的保守规则**，不用 DGM 的隐式晋升。
