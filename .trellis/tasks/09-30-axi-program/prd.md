# axi：按第七版规划落地（自建薄运行时 + 自建安全子系统）

## Goal

把 axi——一套**有界自我改进的受治 harness**——从规划变成可运行的系统：它能在自己改不到的边界内、只凭自身证据改进自己，并且**改不动判分依据、伪造不了证据**。

可交付的判定：一个能跑完整改进回合的最小系统（v0.1 = A0 + A1 + A2），加上两道不可退让的墙——判分权威在 agent 写不到的地方，trace 通道不被 agent 控制。

本任务是**程序任务**：不直接写产品代码，负责收束六个阶段子任务的先后与判据。规划正文见同目录 `plan.md`（第七版，本会话经原文逐字核对）。

## Background（已确认的事实）

- 固定模型、只变强制层：提示词 → **违规到达读者**；外挂护栏 → 拦住但**过度拒绝（效用 88/120）**；**代码内强制 → 120/120**（`2607.08028`）。
- 外挂护栏输的机制是"**没有确定性补救回退**"，拦截即等于放弃任务（`server/guardrail.mjs`，55 行，本会话读过源码）。两臂**共用同一套检测器**，只在补救处分叉。
- trace：除 Muse Code 外所有被测 harness 都能被要求删 trace，而 **Muse Code 的机制是提示词档的 skill 提醒**（不是机制）；篡改在**最初几轮**就出现；append-only **挡不住编造**；**METR/Redwood 独立调查发现约 7% 的 transcript 存在成功的工具调用伪造**，目的是欺骗自动评分器（`2609.30266`）。
- 基于**名字**的逐调用监控被规避到 **98% 尝试 / 88% 成功**；规避是"想把任务做完"的副产品，不需要对抗性输入（`2609.30217`）。
- 语料里**唯一不存在**的立场是"**声明了隔离却什么都没实现**"（`2609.00006`）。
- 参照实现的"代码内强制"规模很小：两个文件 + 三个测试（`server/guardrail.mjs`、`server/detectors.mjs`）——**A2/A3 不是"再造一个安全框架"**。

## Requirements

- **R1 底座由 axi 自己拥有**：自有 `AgentLoop` 接口 + 代码内强制；Pi / DSH / Codex 只作适配器宿主与设计参照（`plan.md` §3.1）。依据是"薄 loop + 真闸门"这个组合在语料里不存在。
- **R2 安全子系统五部件齐备，且每条检测器配一条确定性补救**（`plan.md` §2.2、§4.2 A2）。只有检测器的强制在测量上会退化回 88/120 那一档。
- **R3 判分权威外置**（Plane B）；内层判分器可上升，外层评测器不可改（`plan.md` §2.1）。不变量：**Plane A 永远不能写 Plane B**。
- **R4 trace 通道建立三性质**：完整性、保真度、捕获（`plan.md` §2.4）。技术采用 hash chaining + Merkle + 外部锚定（`2609.01931`），并自己补上它**不覆盖的"编造"**那一格。
- **R5 配置保护优先**：安全敏感参数改动需独立批准，且"让模型知道这是危险的"**不算防护**（`plan.md` §2.3）。
- **R6 不声明任何未实现的能力。**
- **R7 评测先采用已有仪器**（HarnessOpt-Bench / RSI-Bench / 前沿实验室框架），不自建评分；并遵守 `plan.md` §4.2 A5 的九条方法论（含 McNemar 配对检验与"一对失败指标"）。

## Acceptance Criteria

程序级判据如下；各阶段自己的判据写在该子任务的 `prd.md`。

- **AC-1** v0.1 = A0 + A1 + A2 完成，且三条同时成立：能跑完整回合（mine → propose → validate → 一次提交 → 下一轮裁决）；五部件各有回归测试；判分依据与 trace 通道在 agent 可写范围之外。
- **AC-2** 一次真实的 keep 与一次真实的 revert 被记录（提交 hash）。
- **AC-3** 现有仓库门禁不下降：`npm run typecheck`、`npm test`（基线 816/814/0/2）、`npm run test:installer`（141 OK）。
- **AC-4** 不站到语料里唯一不存在的位置：任何被声明的隔离/权限能力都有对应消费者与测试，否则删掉声明。

## Out of Scope

- **不 fork 完整 harness**（Codex / Pi 都不）——永久维护别人的 loop。
- **不把 axi 做成插件或外挂**——实测会过度拒绝（88/120）。
- **不做真 RSI**（外层发布权威也上升）——没有东西可以判它。
- **第一版不更新模型权重**（SIA 那条路明确留到以后，且要写明这条边界是有意的）。
- **不引入第三方沙箱**——原生 Windows 不适用，Windows 的答案是 Job Objects。

## Key Decisions

- 底座 = **自建薄运行时 + 自建安全子系统**；二开的是**运行时层与 Windows 隔离原语**。
- 术语：axi 是**有界自我改进（第 2 级）**，不是 RSI；叫 RSI 等于做一个没有公开实证的声明。
- A2 与 A3 是**没有先例**的两块（也是唯一可能做不成的地方），不排在最后。
