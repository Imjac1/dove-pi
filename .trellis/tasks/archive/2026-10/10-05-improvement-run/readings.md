## 本轮我自己撞出来的一条新红（记在这里，不藏）

第一次全量跑出现**新红**：`tests/spec-anchors.test.ts` → **20 条**（`expected 0 / actual 20`），全部指向新页。原因不是内容，是**引用形状**：

- 我把出处写成裸名：`` `plan.md:41-50` ``、`` `framework.md:112-116` ``。
- 而**锚点门从仓库根解析每条引用**：`plan.md` / `framework.md` 在根上不存在 → 20 条全部"路径不解析"。
- 修法：改成 `` `.trellis/tasks/09-30-axi-program/plan.md:41-50` `` 与 `` `.trellis/tasks/09-30-substrate-choice/framework.md:112-116` ``；并核对**被引行不超过文件行数**（`plan.md` 595 行、`framework.md` 194 行；本轮最大被引 99 / 190）。修后 3/3 绿。

**这是一条新知识**：`spec-anchors` 比 `document-drift` 严。`document-drift` 只要求 `.trellis` / `src` / `tests` / `scripts` 开头的**代码跨度路径存在**；`spec-anchors` 要求**每条 `path:line` 从仓库根可解析、且行号存在**，而且它会把**裸文件名**也算作一条引用。三页里新页是**第一页因为这条门红过的**。

**本轮我自己的另一个错**：新页第一次写出来时**漏了 `## 1.`**（页面直接从 §2 开始）——同一个错在上一页（`personal-agent-usage.md`）也犯过一次。两次都是"标题定稿"那一步写骨架时省略了第一节，靠 `Select-String '^## '` 的数数才发现。
