# Design: name what is there

## The two lines

```markdown
**Pre-Development Checklist**: read the guideline files below that apply to your task, and the router
(`personal-agent-runtime.md`) for the subject-scoped specifications. The index is not the guideline: it is the list.

**Quality Check**: `quality-guidelines.md` holds the forbidden patterns, the required patterns and the review checklist this
repository enforces.
```

**Why naming rather than writing**: the workflow promises a checklist and a quality check, both already exist under other names, and a
round that wrote new guidance would be answering a question nobody asked. What is broken is the *pointer*, and it is fixed by saying
what the parts are.

## The check, and its limit

A presence assertion in the check that already reads both indexes: each names a Pre-Development Checklist and a Quality Check. **It
cannot see whether they say anything useful**, and it says so - the same limit the index rule carries, where a row pointing at the
wrong specification resolves and no check can tell.
