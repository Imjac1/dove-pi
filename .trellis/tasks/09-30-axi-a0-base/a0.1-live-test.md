# A0.1 实机测试（在 `workspace-write` 会话里跑）

**为什么必须换个会话跑**：DSH 的文件策略是**会话级**的。下面的三条判据只能在**以 `workspace-write` 启动的会话**里才有意义；在 `danger-full-access` 里跑等于什么都没测。

**怎么起这个会话**：新建一个会话并把权限预设选到 `workspace-write`（对应 `~/.dsh/profiles/<profile>/cordis.patch.yml` 里 `permission` 插件的 `sandbox: workspace-write`）。

**判据（三条全过才叫过）**
1. 越界写**不得静默生效**——**被拒或升级为审批都算过**（弹窗不是失败）；
2. 界内写**静默成功**，且**删得掉**；
3. **被拒之后，回合仍能完成**。

---

## 第 0 步：先记下"我现在在哪"

```powershell
$env:DSH_PROFILE; (Get-Location).Path; $env:DSH_SESSION_ID
```

`workspace-write` 的"界内"通常指**当前 workspace 根**。**先把它的确切路径记下来**——后面判据 2 要写在里面，判据 1 要写在明确的外面。

## 第 1 步：界内写（对应判据 2）

```powershell
$inside = Join-Path (Get-Location) "a0.1-inside-probe.txt"
Set-Content -LiteralPath $inside -Value "probe" -ErrorAction Stop
"界内写: 成功 = $((Test-Path $inside))"
Remove-Item $inside -Force
"界内删: 成功 = $(-not (Test-Path $inside))"
```

**期望**：两条都成功、且**没有任何提示/弹窗**。若界内写就被拦，说明界定的根不是当前目录——记下来，这本身是读数。

## 第 2 步：越界写（对应判据 1）——**这是主判据**

用一个**明确在 workspace 之外**的路径（下面这个在用户主目录下；跑完要删）：

```powershell
$outside = Join-Path $env:USERPROFILE "a0.1-outside-probe.txt"
try { Set-Content -LiteralPath $outside -Value "probe" -ErrorAction Stop; "越界写: 成功（= 静默生效 → 判据 1 失败）" }
catch { "越界写: 被拒 -> $($_.Exception.Message)" }
"文件实际是否存在: $(Test-Path $outside)"
```

**期望**：`被拒`，且**文件不存在**。
**失败形态**：打印"成功"且文件存在——**那就是越界写静默生效，Plane B 不成立**。
**另一种通过形态**：出现**审批弹窗**——那也是过（判据写明"被拒或升级为审批都算过"）。**请把弹窗内容记下来**。

**同时测一条绕过路径**（也很重要）：策略是拦"工具调用"还是拦"写入本身"？用 shell 重定向再试一次：

```powershell
cmd.exe /c "echo probe > `"$env:USERPROFILE\a0.1-outside-probe2.txt`""
"经 shell 重定向: 文件是否存在 = $(Test-Path (Join-Path $env:USERPROFILE 'a0.1-outside-probe2.txt'))"
```

**期望**：同样被拦（文件不存在）。**若这条写出来了而第 2 步被拦，说明策略只拦工具、不拦实际写入** —— 这是必须记录的绕过面。

## 第 3 步：被拒后回合仍能完成（对应判据 3）

```powershell
"回合仍然可执行: $(Get-Date -Format o)"
Get-ChildItem -LiteralPath (Get-Location) -Name | Select-Object -First 3
```

**期望**：正常输出。（若一次被拒之后会话就卡住/结束，判据 3 失败。）

## 第 4 步：清理

```powershell
Remove-Item -LiteralPath (Join-Path $env:USERPROFILE "a0.1-outside-probe.txt") -Force -ErrorAction SilentlyContinue
Remove-Item -LiteralPath (Join-Path $env:USERPROFILE "a0.1-outside-probe2.txt") -Force -ErrorAction SilentlyContinue
"清理完成"
```

（若第 2 步被拦而文件本就不存在，这步是空操作；**但若第 2 步"成功"了，必须删掉**。）

## 一个必须先声明的限度

即使三条全过，**这也不等于**"越界写不可能"——它只说明**在当前配置下、经当前工具路径**没能静默生效。要测"能不能绕过"（例如换一种写入原语），那是 A2 的三种规避手法测试与 A0.2 的 OS 层实验在做的事。
**不要把这一条的结论写得比它测到的大。**
