# A4 设计：外部闸门、manifest、回路与不变量

## 边界

本任务把"有界"落成机制：判分权威外置（Plane B）、内层可上升而外层不可改、以及**Plane A 永远不能写 Plane B**。

## 决策 1：外部闸门的形态 → **独立进程 + sealed grammar**

候选改动只有在其"事实"能被**外部**推导时才被放行（`2609.30219` 的原话：*"released only when both facts can be derived by an external gate under a sealed grammar"*）。

落地：
- 闸门是**独立进程**（不是 loop 里的一个函数），输入是 manifest + 候选改动 + held-out 结果；
- **sealed grammar**：判定用的语法/规则对提议者**不可见、不可改**；
- 闸门的输出是裁决（release / reject），**不是建议**。

## 决策 2：manifest 四件与其存放

四件：**证据**、**根因**（≠ verifier 层的原因）、**修法**、**预测 + 风险**。

存放：**Plane A 写 manifest，Plane B 读**。这条方向性本身就是要保护的对象（见决策 5）。

## 决策 3：接受语义 → **Self-Harness 的保守规则**，不用 DGM 的隐式晋升

DGM 的"接受"默认 `keep_all`，晋升靠"谁被选为父节点"隐式发生——**取它的机制，不取它的语义**：

| 取自 DGM（机制） | 取自 Self-Harness（语义） |
|---|---|
| `filter_compiled` 式**廉价预闸门** | **只在不损害任一侧时才接受** |
| **两级评估**：阈值 = 档案第二高分（下限 0.4），提交量不足 90% 不计入 | 保守晋升，避免在噪声上做决策 |
| **`noise_leeway` 噪声余量** | |
| **树形档案**（`parent_commit` / `children_count`）+ 可续跑 | |

**保留率期望 ≈3%**（Karpathy：~700 次实验保留约 20 个）→ **成本在门，不在提案**。

## 决策 4：双时间尺度（"递归"的操作化）

- **快回路**：改 harness 本身。
- **慢回路**：改**回路的组件**（产生改进的那个机制），照 MetaSkill-Evolve 的双时间尺度。
- **Plane B 两者都不许改**——这是"内层可上升、外层不可改"的具体分工。

## 决策 5：不变量的强制方式 → **路径 + 独立进程 + 测试**（三件同时）

只靠路径约定不够（那正是语料里"声明了却做不到"的形态）。三条同时：

1. **路径**：Plane B 的目录在 workspace 之外（依赖 A0.1 的结论）；
2. **进程**：闸门是独立进程，不以相同身份运行；
3. **测试**：一条测试**尝试让 Plane A 写 Plane B 并必须失败**。

## HITL 的边界与限度

- **权限边界类改动必须 HITL**（解剖 §3.5.3 原文：改变权限边界、网络访问、凭据处理、部署、人审的改动）。
- **但人批不是万无一失**：`2609.30219` 实测 431 组人答配对里 **169 组放行了错误答案**。所以**不得把"人批过"当作正确性证明**——确定性校验仍要兜底。

## 拒绝也要入库

被拒绝的尝试作为**可审计经验**保留（AI4AI at Scale 的做法），与本仓 `contradicted` 裁决同向。被采纳的更新是**带版本的制品 + 可回退提交**（Reef 的做法）。

## 风险

- **闸门退化成建议** → 一旦输出可以被"参考一下"，它就不是发布权威。
- **慢回路把外层也改了** → 这是真 RSI，没有东西可以判它；要用决策 5 的三件看住。
