# axi：按第七版规划落地（产品与运行时同仓）

## Goal

把 axi——一套**有界自我改进的受治 harness**——从规划变成可运行的系统：它能在自己改不到的边界内、只凭自身证据改进自己，并且**改不动判分依据、伪造不了证据**。

**可交付的判定**：一个能跑完整改进回合的最小系统（v0.1 = A0 + A1 + A2），加上两道不可退让的墙——判分权威在 agent 写不到的地方，trace 通道不被 agent 控制。

**"axi"在这份任务里是一个层名，不是一个仓名**（2026-09-30 晚的形状决定）：运行时与产品在**同一个仓**。

本任务是**程序任务**：不直接写产品代码，负责收束六个阶段子任务的先后与判据。规划正文见同目录 `plan-v8.md`。

## Background（已确认的事实）

- 固定模型、只变强制层：提示词 → **违规到达读者**；外挂护栏 → 拦住但**过度拒绝（效用 88/120）**；**代码内强制 → 120/120**（`2607.08028`）。
- 外挂护栏输的机制是"**没有确定性补救回退**"，拦截即等于放弃任务（`server/guardrail.mjs`，55 行，本会话读过源码）。两臂**共用同一套检测器**，只在补救处分叉。
- trace：除 Muse Code 外所有被测 harness 都能被要求删 trace，而 **Muse Code 的机制是提示词档的 skill 提醒**（不是机制）；篡改在**最初几轮**就出现；append-only **挡不住编造**；**METR/Redwood 独立调查发现约 7% 的 transcript 存在成功的工具调用伪造**，目的是欺骗自动评分器（`2609.30266`）。
- 基于**名字**的逐调用监控被规避到 **98% 尝试 / 88% 成功**；规避是"想把任务做完"的副产品，不需要对抗性输入（`2609.30217`）。
- 语料里**唯一不存在**的立场是"**声明了隔离却什么都没实现**"（`2609.00006`）。
- 参照实现的"代码内强制"规模很小：两个文件 + 三个测试（`server/guardrail.mjs`、`server/detectors.mjs`）——**A2/A3 不是"再造一个安全框架"**。
- **Plane B 的强制力已实测**（A0.2 后半）：非提升进程建 ACL + **受限令牌**（restricting SID = `Everyone`）起改进者，三条判据全过（写不进 / **摘不掉** / 仍能干活），并有正向对照。**可用档位是 `Everyone`**，`BUILTIN\Users` 档在初始化即退出 `0xC0000022`。**Job Objects 不限制文件系统写**（旧措辞已修正）。
- **门禁底线已建立**（S0）：同一棵树三条读数为 `typecheck` 0 · `test` 816/814/0/2 · `test:installer` 141；jailer 落地后为 **822/820/0/2** 与 141（`09-30-axi-a1-skeleton/readings.md`、`09-30-axi-a2-safety/readings.md`）。

## Requirements

- **R1 底座由 axi 自己拥有**：自有 `AgentLoop` 接口 + 代码内强制；Pi / DSH / Codex 只作适配器宿主与设计参照。依据是"薄 loop + 真闸门"这个组合在语料里不存在。
- **R2 安全子系统五部件齐备，且每条检测器配一条确定性补救**。只有检测器的强制在测量上会退化回 88/120 那一档。
- **R3 判分权威外置**（Plane B）；内层判分器可上升，外层评测器不可改。不变量：**Plane A 永远不能写 Plane B**。**强制形态已定**：axi 自己的 jailer 布 ACL + 受限令牌。
- **R4 trace 通道建立三性质**：完整性、保真度、捕获。技术采用 hash chaining + Merkle + 外部锚定，并自己补上它**不覆盖的"编造"**那一格。
- **R5 配置保护优先**：安全敏感参数改动需独立批准，且"让模型知道这是危险的"**不算防护**。
- **R6 不声明任何未实现的能力。**
- **R7 评测先采用已有仪器**（HarnessOpt-Bench / RSI-Bench / 前沿实验室框架），不自建评分；并遵守九条方法论（含 McNemar 配对检验与"一对失败指标"）。
- **R8 同一棵树上的施工纪律**（**2026-09-30 晚修订**，原文是"新仓库与门禁"）。运行时层放本仓 `src/`（`gate` / `jailer` / `trace` / `plane-b`）；**一次逻辑改动 = 一次提交**；**每步门禁不下降且有原始读数**。建设期的隔离靠**分支 + 门禁**，不靠另开一个仓——那是施工棚，不是终点。
- **R9 框架那一半从同一仓抽出**：可搬运包 = 规格树 + 脚本/钩子 + 工作流 + 回合指南 + 门禁，判据是**在一个空仓里装上它，门禁能跑、规格能被路由、回合能走完**（"类似 Trellis"这句要求的落地形态）。

## Out of Scope

- **不 fork 完整 harness**（Codex / Pi 都不）——永久维护别人的 loop。
- **不把 axi 做成插件或外挂**——实测会过度拒绝（88/120）。
- **不做真 RSI**（外层发布权威也上升）——没有东西可以判它；**第 3 级**写成研究问题，不写成交付物。
- **第一版不更新模型权重**（SIA 那条路明确留到以后，且要写明这条边界是有意的）。
- **不引入第三方沙箱**——原生 Windows 不适用，Windows 的答案是 ACL + 受限令牌。
- **不再需要**"不因 axi 改动 dove-pi 的产品代码"这条**终点**约束（形状决定已把它废除）；它作为**施工期**纪律保留：改动走分支，每步门禁不下降。

## Key Decisions

- 底座 = **自有薄运行时 + 自有安全子系统**；二开的是**运行时层与 Windows 隔离原语**。
- 术语：axi 是**有界自我改进（第 2 级）**，不是 RSI；叫 RSI 等于做一个没有公开实证的声明。
- A2 与 A3 是**没有先例**的两块（也是唯一可能做不成的地方），不排在最后——**S3（jailer）已据此提前到 S1 之前执行**。
